PrepStack – Peer-to-Peer Mock Interview Platform
PrepStack is a full-stack MERN-based mock interview platform designed to connect interviewers and interviewees for real-time interview practice. The platform supports role-based authentication, interview scheduling and management, real-time video communication using WebRTC, live chat with Socket.IO, and a collaborative code editor with multi-language code execution for technical interviews.
PrepStack also includes features such as user profiles, interview history, notifications, leaderboards, screen sharing, media controls, and real-time synchronization between participants. The application uses MongoDB, Express.js, React.js, Node.js, Socket.IO, WebRTC, JWT authentication, and cloud-based code execution, with the frontend and backend deployed separately.
Tech Stack: React.js, Node.js, Express.js, MongoDB, Socket.IO, WebRTC, JWT, Tailwind CSS, Monaco Editor, Cloudinary, E2B Code Interpreter, Vercel, and Render.
